# Hard-Real-RBG

A Unity C# prototype for a realistic open-world RPG with layered profession paths, dynamic prices, and a world war between humans and demons.

## Included systems

- Profession paths: Aristocrat, Worker, Villain, Hero
- Worker roles: Farmer, Blacksmith, Carpenter, Hunter, Miner, Baker, Tailor
- Villain roles: Bandit, Smuggler, Assassin, Cultist, Mercenary
- Hero roles: Knight, Paladin, Ranger, Mage, Cleric
- Dynamic economy: food, housing, raw materials
- World events: war, harvest, demon influence, morale

## Folder structure

- Assets/Scripts/Character/ProfessionPath.cs
- Assets/Scripts/World/WorldState.cs
- Assets/Scripts/World/EconomySystem.cs
- Assets/Scripts/World/WorldSimulationExample.cs

## Quick concept

The game is designed around a world in which player choices shape social status, survival, and political power. The economy reacts to war, harvest quality, and demonic pressure. Player careers are not fixed; they can move from worker to aristocrat, from hero to villain, or between them depending on actions.
